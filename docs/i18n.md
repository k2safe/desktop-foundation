# I18n

桌面底座提供一层轻量多语言能力，用来覆盖通用 UI、登录壳、调试面板、表格、弹窗、toast、文件选择、设置页等基础文案。业务产品仍然拥有自己的品牌、菜单、页面标题、字段名、接口错误和业务文案。

## 内置语言

- `zh-CN`
- `en-US`

默认语言是 `zh-CN`。如果产品不传任何语言配置，底座通用文案会使用中文默认值。

## App Shell 接入

产品项目优先从 `DesktopAppShell` 传入语言配置：

```tsx
import { DesktopAppShell } from "@desktop-foundation/app-shell";

const messages = {
  "layout.logout": "Sign out",
  "login.signIn": "Enter workspace"
};

export function App() {
  return (
    <DesktopAppShell theme={theme} client={clientConfig} locale="en-US" messages={messages}>
      <Routes />
    </DesktopAppShell>
  );
}
```

自定义语言使用 `dictionaries`：

```tsx
const dictionaries = {
  "ja-JP": {
    "common.cancel": "キャンセル",
    "common.confirm": "確認",
    "layout.logout": "ログアウト"
  }
};

<DesktopAppShell locale="ja-JP" dictionaries={dictionaries} theme={theme} client={clientConfig}>
  <Routes />
</DesktopAppShell>;
```

## UI 组件单独使用

如果没有使用 `DesktopAppShell`，可以在 UI 层直接包 `LocaleProvider`：

```tsx
import { LocaleProvider } from "@desktop-foundation/ui-react";

<LocaleProvider locale="en-US">
  <ProductScreen />
</LocaleProvider>;
```

组件内部可以通过 `useLocale()` 读取：

```tsx
import { useLocale } from "@desktop-foundation/ui-react";

function SaveButton() {
  const { t } = useLocale();
  return <button type="button">{t("common.confirm")}</button>;
}
```

## 覆盖规则

优先级从低到高：

1. `zh-CN` 默认字典
2. 内置目标语言字典，比如 `en-US`
3. `dictionaries[locale]`
4. `messages`
5. 业务组件显式传入的 prop，比如 `submitLabel`、`title`、`emptyTitle`

这意味着产品可以只覆盖少量 key，不需要复制整份字典。业务显式传入的文案永远优先，底座不会替产品翻译业务页面。

## Product Adapter 推荐形态

```tsx
import type { LocaleCode, LocaleDictionary } from "@desktop-foundation/ui-react";

export interface ProductAdapter {
  locale: LocaleCode;
  messages?: LocaleDictionary;
  dictionaries?: Record<string, LocaleDictionary>;
}

export const productAdapter: ProductAdapter = {
  locale: "en-US",
  messages: {
    "layout.logout": "Sign out"
  }
};
```

然后在入口传给 `DesktopAppShell`：

```tsx
<DesktopAppShell
  theme={productAdapter.theme}
  client={client}
  locale={productAdapter.locale}
  messages={productAdapter.messages}
  dictionaries={productAdapter.dictionaries}
>
  <Routes />
</DesktopAppShell>
```

## 底座边界

底座负责：

- 通用按钮、弹窗、toast、表格、筛选、命令面板、登录壳默认文案
- `zh-CN` / `en-US` 内置字典
- 自定义语言字典注入
- `{count}`、`{key}` 这类简单占位符替换

产品负责：

- 产品名、菜单、路由、页面标题
- 业务字段、接口错误、权限名
- 需要专业翻译或上下文强相关的文案
